# 🥕 食材きげん帳

家族みんなのスマホから、冷蔵庫の食材の **消費期限・賞味期限** を記録・確認できるWebアプリです。
アプリのインストールやアカウント登録は不要で、URLを開くだけで使えます。

## できること

- 食材の登録：名前・期限日（「明日」「+1週間」などのワンタップ入力）・消費期限／賞味期限・保存場所（冷蔵／冷凍／野菜室／常温）・数量・メモ
- 期限が近い順に並べて、色で表示（赤＝期限切れ、橙＝2日以内、黄＝1週間以内、緑＝それ以降）
- 「期限切れ」「3日以内」の件数表示と絞り込み、保存場所タブ、検索
- 「1つ使った」で数量を1減らし、「使い切った」でリストから削除（誤操作は「元に戻す」で戻せます）
- だれが登録・更新したかを表示
- **家族で共有**：Googleスプレッドシートにデータを保存し、全員が同じリストを見られます（1分ごと・アプリを開いたときに自動同期）
- ホーム画面に追加すると、普通のアプリのように起動できます

## 公開URL

GitHub Pages で公開している場合は、次のURLで開けます。

```
https://<ユーザー名>.github.io/rabbit-invader/food/
```

## 家族で共有する設定（最初に1回・約5分）

共有サーバーには **Google スプレッドシート + Google Apps Script** を使います（無料）。

1. [Google スプレッドシート](https://sheets.new) で新しいシートを作成（名前は「食材きげん帳」など）
2. メニューの **拡張機能 → Apps Script** を開く
3. 最初から入っているコードを全部消し、[`gas/Code.gs`](gas/Code.gs) の中身を貼り付けて保存
   - 家族以外に使われないようにしたい場合は、先頭の `const PASSCODE = '';` に合言葉を入れてください（例：`'usagi2026'`）
4. 右上の **デプロイ → 新しいデプロイ**
   - 種類の選択：⚙ → **ウェブアプリ**
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
   - 「デプロイ」を押し、Googleアカウントのアクセス許可を承認
5. 表示された **ウェブアプリのURL**（`https://script.google.com/macros/s/…/exec`）をコピー
6. スマホでアプリを開き、⚙ 設定 → 「共有サーバーURL」に貼り付け（合言葉を決めた場合は「合言葉」にも入力）→「接続テスト」→「設定を保存」
7. 「**家族に招待リンクを送る**」を押して、LINE などで家族に送信

家族は招待リンクを開いて名前を入れるだけで、同じリストを使えるようになります。

> 共有設定をする前に「この端末のみ」で記録していた食材は、共有サーバーを設定したときに共有リストへ自動で移されます。

### 補足

- データはスプレッドシートの `items` シートに1行1食材で保存されます。スプレッドシートから直接確認・バックアップできます。
- `Code.gs` を書き換えたときは、**デプロイを管理 → 編集 → バージョン「新バージョン」** で更新してください（URLは変わりません）。
- 招待リンク・共有サーバーURLを知っている人はリストを読み書きできます。家族以外に広めないようにし、心配な場合は合言葉を設定してください。

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | アプリ本体（HTML / CSS / JavaScript のみ、外部ライブラリなし） |
| `gas/Code.gs` | 家族共有用サーバー（Google Apps Script） |
| `manifest.webmanifest`, `sw.js`, `icon*` | ホーム画面追加・オフライン起動用 |
